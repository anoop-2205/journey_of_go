# Journey of Go

A structured, hands-on learning repository for the **Go programming language** — from hello world to structs and interfaces.

> This is a personal learning repository documenting my progress through Go fundamentals.

---

## What's Inside

| # | Topic | Files |
|---|-------|-------|
| 01 | **Basics** | `hello_world.go`, `variables.go`, `data_types.go` |
| 02 | **Control Flow** | `conditionals.go`, `loops.go` |
| 03 | **Functions** | `functions.go` |
| 04 | **Data Structures** | `arrays_slices.go`, `maps.go` |
| 05 | **Structs & Interfaces** | `structs.go` |

---

## Learning Order

1. `01_basics/hello_world.go` — First Go program
2. `01_basics/variables.go` — Variables, constants, short declarations
3. `01_basics/data_types.go` — All built-in types (int, float, string, bool, etc.)
4. `02_control_flow/conditionals.go` — if/else, switch statements
5. `02_control_flow/loops.go` — for loops (the only loop in Go!)
6. `03_functions/functions.go` — Functions, closures, multiple return values
7. `04_data_structures/arrays_slices.go` — Arrays and slices
8. `04_data_structures/maps.go` — Key-value maps
9. `05_structs_interfaces/structs.go` — Structs, methods, interfaces

## How to Run

**Prerequisites:** Install Go from [go.dev/dl](https://go.dev/dl)

```bash
# Run any file directly
go run 01_basics/hello_world.go
go run 02_control_flow/loops.go
go run 05_structs_interfaces/structs.go

# Check your Go version
go version
```
